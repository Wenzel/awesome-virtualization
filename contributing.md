# Contributing

## Scope

Resources for people who build, break and introspect hypervisors: CPU virtualization internals, hypervisor development, virtual machine introspection and hypervisor security.

Out of scope: management platforms, desktop apps and GUIs, containers that do not use hardware virtualization, sandboxes and CPU emulators. Suggest those to one of the [related lists](README.md#related-lists).

## Entry format

```markdown
- [Title](url) - Author, venue, year. One sentence on what the reader learns or why it matters. ([slides](url))
```

- Link the most stable location: a DOI, the conference page or arXiv for papers; the conference page or the official video for talks.
- For personal blogs, add an archived copy if the original is at risk of disappearing.
- For code, say so when a repository is archived or unmaintained. Unmaintained teaching code is welcome; unmaintained tools are not.
- One entry per pull request, added to the section it fits, in chronological order where the section has one.

## Not accepted

- Projects less than a year old.
- Undisclosed self-promotion. Say so if the project is yours.
- Pull requests generated by an AI without a human having read the resource.
